What is VendSmart?

Product summary
VendSmart is a mobile management platform for vending machine operators. It gives operators a real-time view of their entire fleet — revenue, inventory levels, and alerts — all from one app. It also includes a separate PIN-protected section for delivery couriers, and a customer-facing suggestion page accessed by QR code on the machine.

For Operators

Monitor every machine's revenue, stock levels, and alerts from a single dashboard. Manage inventory, view sales trends, and control machine details.

For Couriers

A separate PIN-locked section shows restocking priorities, turn-by-turn directions to each machine, and a checklist to log what was added.

For Customers

A QR code on each machine opens a suggestion page where customers can vote on items they want to see stocked.

Hardware-Ready

Designed to connect to Arduino + IR sensor hardware. Currently running on dummy data — real sensor data drops in when the hardware is ready.

Machine Detail — 5 Tabs

Tap any machine card to enter the full detail view
▦ Dashboard 📦 Inventory 📈 Trends 💵 Earnings 💬 Suggestions
Tab 1 — Dashboard
  • Live status: Online / Offline with colored indicator
  • Today's revenue, total items in stock, and alert count in large stat cards
  • Alert list shows exactly which slots are empty or running low with red/yellow badges
  • Quick action: reorder link takes operator directly to Costco with one tap
Tab 2 — Inventory
  • Every slot listed with current stock vs. capacity and a visual fill bar
  • Blue banner shows how many items the operator already has in their warehouse
  • "Use My Stock" badge (blue) — item is in the operator's own warehouse; no order needed
  • "Reorder" badge (green, cart icon) — item not in warehouse; one tap opens an order link
  • Saves operators money by using existing warehouse stock before placing new orders
Tab 3 — Trends
  • Bar chart: daily sales for the past 7 days — see which days are busiest
  • Bar chart: peak hours — see exactly when customers buy most (8am, 12pm, 6pm, etc.)
  • Helps operators decide when to schedule restocks and what to stock more of
Tab 4 — Earnings
  • Month-to-date revenue, last month comparison, this week total, and daily average
  • Items sold this month and average sale price
  • Recent sales log: each transaction shows item name, quantity, time, and revenue
Tab 5 — Suggestions
  • Customer-submitted product suggestions, ranked by vote count
  • Operators can thumbs-up suggestions directly in the app
  • Each suggestion shows category (Snack or Drink) and total votes
  • "Order Now" button links directly to Amazon search for that item
  • "View QR Code" button in the header — show this to customers to get the page URL

Warehouse Inventory

Settings → My Warehouse Inventory
Operators often have stock on hand that isn't inside a machine yet. This screen tracks what's in the warehouse so the app can flag "Use My Stock" on the Inventory tab before suggesting a reorder — saving unnecessary purchases.

Summary Stats

Total units across all items, count of items running low (≤6 units), and count of items fully out of stock — visible at a glance.

Search

Filter your inventory list instantly by typing an item name — useful when you have dozens of products.

Quick Quantity Buttons

+/− buttons on each row let operators update quantities with one tap after a delivery, without opening a full edit form.

Add / Edit / Delete

Full CRUD via a modal form. Add item name and quantity, edit existing items, or remove items no longer in stock.

Edit Machine Details

Fleet screen → "Edit Machine Details" on any machine card
  • Machine Name — what appears on all dashboards and courier screens
  • Location Label — short label like "Purdue Union – 1st Floor" shown on the fleet and courier views
  • Street Address — fed directly into the Google Maps link couriers use for navigation
  • Finding the Machine — step-by-step directions from the building entrance to the machine; couriers see this before starting their restock checklist
  • Save button only activates when a change has been made (prevents accidental saves)

Courier Section

PIN-locked area for delivery staff — completely separate from the operator experience
🔒

Access: 4-Digit PIN

Couriers tap "I'm a Courier — Enter PIN" on the login screen. Demo PIN: 1234. Wrong PIN triggers a red shake animation on the dots.

Screen 1 — Courier Home (Machine List)
  • All machines sorted automatically by urgency — most critical at the top
  • Three urgency levels clearly labeled:
    ● Urgent — 4+ alerts ● Needs Restock — 2+ alerts ● All Good
  • Each card shows empty slot count and low slot count so couriers know what to bring
  • Summary row at top: total machines, urgent count, and total alerts across all machines
  • Log Out button (top right) sends the courier back to the main login screen
Screen 2 — Courier Restock (Per-Machine Checklist)
  • Directions button — opens Google Maps with the machine's street address; one tap to navigate
  • "Finding the Machine" card — shows the operator's written instructions for locating the machine inside the building
  • Progress bar updates in real time as the courier checks off slots
  • Each slot shows: slot ID, item name, current stock, how many units are needed to fill it
  • Empty slots are flagged red; low slots flagged yellow so priorities are obvious
  • "Units added" input field for each slot — courier logs exactly what they put in
  • Optional notes field for reporting issues (machine damage, access problems, etc.)
  • Submit button is disabled until every slot is checked — prevents partial reports
  • Success screen shows timestamp, slots restocked count, and machine location for records

Customer Suggestion Page

QR code on the machine → standalone web page
A QR code printed on the vending machine links to a simple web page where customers can suggest what they want stocked. No app download needed — it works in any browser. Suggestions flow directly into the Suggestions tab in the operator's app.
1

Customer scans QR code on the machine

A sticker or printed card on the machine opens the suggestion page in their phone browser.

2

They pick a popular item or write their own

Tap popular suggestion chips (e.g. "Celsius", "Protein Bar") or type a custom item. Choose Snack or Drink category.

3

Optional note — then Submit

They can add a short note ("the cafeteria next door already has Celsius, here you should have…") before submitting.

4

Operator sees it in the Suggestions tab

Items are ranked by votes. Operators can tap "Order Now" to open an Amazon search for that item immediately.

Technology

How it's built

React Native + Expo

One codebase runs on iPhone, Android, and web browser. Currently demoed in a web browser; ready to publish to the App Store and Google Play.

Dummy Data Layer

All machine data lives in a single file (fake-data/dummyData.js). Swapping in real data from the backend is a one-file change.

Arduino + IR Sensors (Planned)

Hardware reads slot fill levels via IR sensors and pushes data to the app. The app UI is already designed around this data structure.

Firebase Backend (Planned)

Real-time database for live machine data, push notifications for alerts, and cloud sync so multiple operators can share a fleet.
